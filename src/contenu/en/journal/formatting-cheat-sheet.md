This note serves as an example and a reminder. It shows how the common elements of an article are displayed.

## Headings and paragraphs

A section heading starts with `##`, a subheading with `###`. The main title comes from the `title` field: it's never written in the text. Use **bold** for what matters and *italics* for what adds nuance.

## Lists

- a bullet list, for items with no order;
- a link is written [like this](https://example.com);
- short code is written `between backticks`.

1. a numbered list
2. for steps in order

## Quote

> A quote is written with a chevron at the start of the line.
