Ressources

Une liste curatée d'outils, liens et références que j'utilise ou recommande.

🐧

ArchWiki

La référence Linux la plus complète qui existe. Utile quelle que soit ta distribution.

resource linux arch docs référence
🚗

BeamNG Forums

La communauté officielle BeamNG.drive. Documentation du modding JBeam, partage de mods, support technique et discussions sur la physique du simulateur.

resource beamng simulation modding communauté
⚡

CachyOS

Distribution Arch-based avec kernel patché pour la performance (BORE, EEVDF), paquets recompilés avec optimisations CPU. Idéal pour le gaming et les workloads latency-sensitive.

resource linux arch performance gaming
📚

FMHY — Free Media Heck Yeah

La plus grande liste collaborative de ressources pour les médias gratuits et libres. Organisée par catégorie : streaming, téléchargement, outils, privacy, éducation et bien plus.

resource ressources médias privacy outils
🎬

Jellyfin

Serveur multimédia open-source auto-hébergé. Gère films, séries, musique et photos. Alternative libre à Plex, sans abonnement ni télémétrie.

resource médias self-hosted open-source streaming
🎵

Lidarr

Gestionnaire automatisé de musique, dans l'écosystème *arr. Surveille les sorties d'artistes, télécharge et organise ta discothèque.

resource médias self-hosted automatisation musique
🔒

Mullvad VPN

VPN suédois sans logs, sans compte email requis (identifiant anonyme), paiement en cash ou crypto accepté. L'un des rares VPN audités qui tient ses promesses de privacy.

resource privacy vpn sécurité
🛡️

Privacy Guides

Référence pour choisir des outils respectueux de la vie privée. VPN, navigateurs, DNS, messageries, systèmes d'exploitation — recommandations basées sur des critères objectifs et vérifiables.

resource privacy sécurité référence outils
🔍

Prowlarr

Gestionnaire centralisé d'indexeurs pour Sonarr, Radarr et les autres apps *arr. Configure une fois, synchronise partout.

resource médias self-hosted automatisation indexeurs
🌊

qBittorrent

Client BitTorrent open-source sans publicité ni bundleware. Interface propre, supporte les trackers privés, le VPN binding et l'interface web pour le headless.

resource outils torrent open-source
🎥

Radarr

Même chose que Sonarr mais pour les films. Surveille les sorties, télécharge et organise ta médiathèque automatiquement.

resource médias self-hosted automatisation films
📊

REW — Room EQ Wizard

Logiciel de mesure acoustique. Analyse la réponse en fréquence d'une pièce ou d'un habitacle, génère les corrections EQ. Indispensable pour le tuning audio sérieux.

resource audio mesure acoustique outils
📺

Sonarr

Gestionnaire automatisé de séries TV. Surveille les sorties, télécharge automatiquement via les indexeurs configurés et renomme les fichiers selon ta convention. S'intègre avec qBittorrent et Jellyfin.

resource médias self-hosted automatisation séries
🐵

Violentmonkey

Gestionnaire de userscripts open-source. Alternative à Tampermonkey, sans télémétrie. Compatible Chrome, Firefox et dérivés.

resource outils userscript browser open-source
🔊

WinISD

Logiciel de simulation d'enceintes. Calcule la réponse en fréquence, le déplacement membranaire et la puissance thermique à partir des paramètres Thiele-Small. Gratuit, fonctionne sous Wine.

resource audio diy simulation outils
⬇️

yt-dlp

Fork de youtube-dl activement maintenu. Télécharge des vidéos et de l'audio depuis YouTube et des centaines d'autres sites. Supporte les playlists, les sous-titres, le post-processing ffmpeg.

resource outils cli médias open-source
🔷

TypeScript Playground

Tester du TypeScript directement dans le navigateur, partager des exemples, explorer les options du compilateur.

resource typescript outils
🌐

Can I Use

Vérifier la compatibilité navigateur d'une fonctionnalité CSS, HTML ou JS avant de l'utiliser.

resource css compatibilité outils
⚡

Eleventy — Documentation officielle

La documentation complète d'Eleventy, le générateur de site statique minimaliste.

resource eleventy docs ssg
📚

MDN Web Docs

La référence ultime pour HTML, CSS, JavaScript et les APIs Web. Incontournable.

resource docs web référence

Aucun résultat.
