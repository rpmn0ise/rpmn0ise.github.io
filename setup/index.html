Setup

Mon setup complet — PC, audio, sim-racing, périphériques et logiciels.

Tout est dans ma chambre. Dual-boot Windows 11 / CachyOS sur le PC principal, un vieux Lenovo pour le taf.

Config assemblée moi-même, orientée gaming et simulation.

🖥️ Écrans & Périphériques #

Écrans — 2× Asus 27" 165 Hz

  • Un en horizontal — gaming, navigation principale
  • Un en vertical (pivot 90°) — code, lecture de docs, monitoring

La config dual-screen vertical/horizontal est particulièrement efficace pour le code — avoir la doc en vertical à côté de l’éditeur change vraiment le workflow.

Clavier — Royal Kludge M87 (mécanique, TKL 87%)

Compact sans pavé numérique, switches mécaniques. Bon rapport qualité/prix pour du mécanique sans payer une fortune.

Souris — Logitech G305 (sans fil, capteur HERO)

Légère, autonomie longue, récepteur USB nano. Le sans fil à ce prix c’est difficile à battre.

🔊 Audio — Home Cinéma #

Le système audio est branché sur le PC principal — setup home cinéma dans la chambre.

Le subwoofer dont il est question dans les articles du blog fait partie de ce système. L’acoustique d’une chambre est un challenge différent d’un salon — les modes de résonance dans un petit espace sont plus prononcés et plus difficiles à corriger.

Setup en cours de documentation — un article détaillé sur la configuration et le tuning REW arrive.

🏎️ Sim-Racing #

Volant — Logitech G29 (FFB direct drive entry-level)

Le G29 est le point d’entrée du sim-racing avec retour de force. L’encodeur optique du volant a une résolution correcte pour du BeamNG et des sims grand public.

Boîte de vitesses — Logitech Driving Force Shifter (H-pattern)

Indispensable pour les jeux sans boîte automatique — et pour BeamNG où les transmissions manuelles ont un vrai comportement physique.

Pédalier — G29 stock modifié

Le frein stock du G29 est trop mou et progressif — difficile de doser le freinage avec précision. Upgrade réalisé pour augmenter la résistance et améliorer le feedback. Le résultat est un pédalier beaucoup plus utilisable en conditions de simulation sérieuse.

Position — Chaise de bureau standard

Pas de cockpit dédié pour l’instant. La chaise de bureau avec le volant clampé sur le bureau est moins immersif mais suffisant pour du BeamNG quotidien.

Projet futur : cockpit sim-racing maison en profilé aluminium.

🐧 Logiciels & OS #

Dual-boot — Windows 11 / CachyOS

  • Windows 11 — gaming (compatibilité anti-cheat, Forza, etc.)
  • CachyOS — tout le reste : développement, navigation, outils, quotidien

CachyOS est une distribution Arch-based avec un kernel patché (BORE scheduler, optimisations CPU) et des paquets recompilés pour les architectures récentes. Concrètement : meilleure réactivité, latences plus basses, gaming Linux plus fluide.

Éditeur — VS Code (sur le Lenovo principalement)

Terminal — Kitty ou Alacritty selon les humeurs

Shell — Zsh + plugins

Navigateur — Firefox avec uBlock Origin

💼 PC Secondaire — Travail #

Lenovo IdeaPad 3 (ancienne génération)

Dédié au travail : VS Code, documentation, outils de dev légers. Le fait de séparer physiquement gaming et travail sur deux machines différentes évite les distractions et simplifie la configuration de chaque machine pour son usage.

📱 Mobile #

Xiaomi POCO F7 Pro

Le POCO F7 Pro est un flagship killer — Snapdragon haut de gamme, écran AMOLED, charge rapide, pour un prix bien en dessous des Galaxy et iPhone équivalents. Stock MIUI/HyperOS pour l’instant.
